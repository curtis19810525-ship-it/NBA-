# NBA 明日賽事爬蟲使用說明

## 📋 功能說明

`nba_future_fetcher.py` 是一個自動化腳本，用於：
1. 爬取 Playsport 明日（today + 1）的 NBA 賽事預測資料
2. 自動將資料寫入 `NBA25-26.xlsx` 的新分頁
3. 自動備份昨日分頁到 `NBA25-26歷史資料.xlsx`
4. 自動清理主檔案中的昨日分頁

## 🚀 快速開始

### 方法 1：雙擊執行（推薦）
直接雙擊 `執行明日賽事爬蟲.bat` 即可執行

### 方法 2：命令列執行
```bash
cd "抓取NBA網路資料"
python nba_future_fetcher.py
```

## 📁 檔案說明

### 主要檔案
- `nba_future_fetcher.py` - 主程式腳本
- `執行明日賽事爬蟲.bat` - 批次執行檔

### 相關檔案
- `config.py` - 設定檔（定義檔案路徑）
- `NBA25-26.xlsx` - 主統計表（位於 OneDrive）
- `NBA25-26歷史資料.xlsx` - 歷史資料備份（與主檔案同目錄）

## 📊 資料結構

### Excel 分頁命名
- 分頁名稱格式：`YYYYMMDD`（例如：`20251220`）

### 資料寫入位置
每場比賽垂直間隔 15 列，起始列計算公式：
- 第 N 場起始列 = (N-1) × 15 + 2

### 欄位對應
| 欄位 | 內容 | 說明 |
|------|------|------|
| B{Row_Start} | 比賽時間 | 例如：06:00 |
| C{Row_Start} | 客隊名稱 | 例如：湖人 |
| D{Row_Start} | 客隊讓分門檻 | 例如：+2 或 -5.5 |
| E{Row_Start} | 客隊預測比例 | 例如：65% |
| F{Row_Start} | 主隊名稱 | 例如：勇士 |
| H{Row_Start} | 主隊預測比例 | 例如：35% |

**注意**：G 欄被跳過（保留空白）

## 🔄 自動備份機制

### 備份流程
1. 檢查 `NBA25-26.xlsx` 中是否存在「昨日日期」的分頁
2. 如果存在，將該分頁完整複製到 `NBA25-26歷史資料.xlsx`
3. 確認備份成功後，從主檔案中刪除該分頁

### 歷史資料檔案
- 如果 `NBA25-26歷史資料.xlsx` 不存在，程式會自動建立
- 歷史資料檔案與主檔案位於同一目錄

## 🌐 爬取目標

### 網址格式
```
https://www.playsport.cc/predict/scale?allianceid=3&gametime={YYYYMMDD}&sid=0
```

### 抓取資料項
- 比賽時間 (Time)
- 客隊名稱 (Guest Team)
- 主隊名稱 (Home Team)
- 客隊讓分門檻 (Guest Spread)
- 客隊預測比例 (Guest Percentage)
- 主隊預測比例 (Home Percentage)

## ⚙️ 設定說明

### 檔案路徑
檔案路徑定義在 `config.py` 中：
- `NBA_STATS_FILE` - 主統計表路徑（預設：OneDrive 路徑）
- `NBA_HISTORY_FILE` - 歷史資料檔案路徑（自動設定為與主檔案同目錄）

### 日期邏輯
- **目標日期**：自動計算為 today + 1（明日）
- **備份日期**：自動計算為 today - 1（昨日）

## 🐛 故障排除

### 問題 1：無法爬取資料
**可能原因**：
- 網站結構變更
- 該日期沒有賽事
- 網路連線問題

**解決方法**：
1. 檢查程式輸出的錯誤訊息
2. 查看自動儲存的調試 HTML 檔案（`debug_playsport_{日期}.html`）
3. 根據 HTML 結構調整解析邏輯

### 問題 2：無法寫入 Excel
**可能原因**：
- Excel 檔案正在被其他程式開啟
- 沒有寫入權限
- OneDrive 同步問題

**解決方法**：
1. 關閉所有開啟的 Excel 視窗
2. 確認檔案未被鎖定
3. 檢查 OneDrive 同步狀態

### 問題 3：備份失敗
**可能原因**：
- 歷史資料檔案被鎖定
- 磁碟空間不足

**解決方法**：
1. 關閉所有開啟的 Excel 視窗
2. 檢查磁碟空間
3. 手動檢查歷史資料檔案是否存在

## 📝 注意事項

1. **執行時機**：建議在每日固定時間執行（例如：晚上或早上）
2. **檔案備份**：重要資料請定期手動備份
3. **網站變更**：如果網站結構變更，可能需要調整解析邏輯
4. **格式保留**：寫入時會保留 Excel 預設格式，不會破壞格線

## 🔧 自訂調整

如果需要調整解析邏輯，請修改 `fetch_playsport_data()` 函數中的解析部分。如果網站結構變更，可以：
1. 執行腳本後查看 `debug_playsport_{日期}.html`
2. 分析 HTML 結構
3. 調整 BeautifulSoup 解析邏輯

## 📞 支援

如有問題，請檢查：
1. Python 版本（建議 3.7+）
2. 必要套件是否已安裝（`requests`, `beautifulsoup4`, `openpyxl`）
3. 網路連線是否正常
4. 檔案路徑是否正確
